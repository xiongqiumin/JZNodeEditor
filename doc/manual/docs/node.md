# 节点编辑

## 1.基础
- 函数分为流程函数和纯函数，流程函数需连接流程，纯函数需连接数据


### 连接规范
- 输入/输出端口类型必须匹配
- 禁止循环连接

## 2.数据节点
### 常量
- **bool**：</br> bool类型常量，取值为true或false
- **int8-int64**：</br> 整数类型常量
- **uint8-uint64**：</br> 无符号整数类型常量
- **float/double**：</br> 浮点数类型常量
- **string**：</br> 字符串类型常量
- **enum**：</br> 枚举类型常量
- **flag**：</br> 标志类型常量,未对应枚举的组合
- **QByteArray**：</br> 字节数组类型常量
- **nullptr**：</br> 空指针类型常量
- **FunctionPointer**：</br> 函数指针类型常量

### 变量
- **局部变量**：</br> 局部变量
- **成员变量**：</br> 成员变量
- **全局变量**：</br> 全局变量

### 调试
- **format**：</br>  格式化字符串，支持占位符和类型转换
- **print**：</br> 打印节点，用于输出调试信息
- **assert**：</br>  断言节点，用于检查条件是否成立
- **display**：</br>  显示节点，用于实时显示变量值 

## 3.流程节点
- **nop**：</br> 空操作节点，保持流程连续性，用于占位或调试
- **sequence**：</br> 顺序执行节点，依次执行子节点
- **if**：</br> 条件分支节点，根据布尔表达式选择执行路径
- **switch**：</br> 多条件分支节点，支持多种匹配模式
- **while**：</br> 循环节点，满足条件时重复执行
- **for**：</br> 计数循环节点，固定次数迭代执行
- **foreach**：</br> 遍历循环节点，处理集合类数据
- **break**：</br> 循环中断节点，立即退出当前循环
- **continue**：</br> 循环继续节点，跳过本次迭代
- **return**：</br> 流程返回节点，终止当前执行流
- **try/catch**：</br> 异常处理节点，捕获并处理运行时错误
- **throw**：</br> 异常抛出节点，主动触发错误条件

## 4.计算节点
### 算术运算
  - **OP_add**：</br> 加法运算，示例：`a + b`
  - **OP_sub**：</br> 减法运算，示例：`a - b`
  - **OP_mul**：</br> 乘法运算，示例：`a * b`
  - **OP_div**：</br> 除法运算，示例：`a / b`
  - **OP_mod**：</br> 取模运算，示例：`a % b`
  - **OP_neg**：</br> 取负运算，示例：`-a`

### 位运算
  - **OP_bitand**：</br> 按位与，示例：`a & b`
  - **OP_bitor**：</br> 按位或，示例：`a | b`
  - **OP_bitxor**：</br> 按位异或，示例：`a ^ b`
  - **OP_bitreverse**：</br> 位反转，示例：`~a`

### 逻辑运算
  - **OP_and**：</br> 逻辑与，示例：`a && b`
  - **OP_or**：</br> 逻辑或，示例：`a || b`
  - **OP_not**：</br> 逻辑非，示例：`!a`

### 比较运算
  - **OP_eq**：</br> 等于比较，示例：`a == b`
  - **OP_ne**：</br> 不等于比较，示例：`a != b`
  - **OP_le**：</br> 小于等于，示例：`a <= b`
  - **OP_ge**：</br> 大于等于，示例：`a >= b`
  - **OP_lt**：</br> 小于，示例：`a < b`
  - **OP_gt**：</br> 大于，示例：`a > b`

### 单目运算
  - **OP_neg**：</br> 取负运算，示例：`-a`
  - **OP_not**：</br> 逻辑非运算，示例：`!a`
  
### 表达式
  - **OP_expr**：</br> 表达式运算，支持复杂的逻辑表达式，可以调用函数，示例：`a + pow(b, c)`
  
## 5.事件节点
事件节点在外部触发时执行对应的操作，例如定时器、信号等。

## 6.业务节点
业务节点用来实现复杂的业务逻辑
### camera
摄像头节点，用于获取摄像头数据

### model
模型节点，用于调用模型进行推理

### comm
通信节点，用于通信

### opencv
用于 opencv 相关操作

## 7.函数/类节点
包含了全部的函数类，用于细粒度的控制,可作为业务的补充
